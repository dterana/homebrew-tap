# Homebrew tap for Casemate

[Casemate](https://github.com/dterana/casemate) is a future-proof file encryption CLI with versioned formats.

```bash
brew tap dterana/tap
brew trust --tap dterana/tap   # Homebrew 7 only loads third-party taps you have trusted
brew install casemate
casemate version
```

Casemate was called Bitseal until v0.4.0. `tap_migrations.json` maps the old `bitseal` formula to `casemate`, so `brew upgrade` moves existing installs over.

Supported: macOS and Linux, on Intel and ARM. The formula installs the prebuilt binary from the matching
[Casemate release](https://github.com/dterana/casemate/releases) and checks its SHA-256.

## How the formula stays up to date

`Formula/casemate.rb` is generated by `scripts/update-formula.sh` from the checksums of the latest Casemate release
(pre-releases included). The `Update formula` workflow runs it every day and can be started by hand
(Actions, Update formula, Run workflow). When the formula changed it commits the new version and then runs the
`Test formula` workflow (audit, install and `brew test` on macOS and Linux).

To update by hand: `scripts/update-formula.sh [vX.Y.Z]` (needs the GitHub CLI), then commit.
